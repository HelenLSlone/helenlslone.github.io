# Helen Slone – Personal Site & Blog

Personal website and blog for **Helen Slone**, a Software Engineer based in Cambridge, UK.

## About

This site documents AI experiments, side projects, and lessons learned along the way. Helen is a recovering front-end developer transitioning into AI engineering, with a background spanning secondary school teaching, materials science in the steel industry, and over 15 years in software engineering (including team lead experience since 2020). Currently working at [Flagstone](https://flagstone.com), a cash deposit platform.

[Visit the site →](https://helenlslone.github.io)

## Stack

- **[Jekyll](https://jekyllrb.com/)** – static site generator
- **[Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes)** theme (dark skin)
- Hosted on **GitHub Pages** (`gh-pages` branch)

## Running Locally

```bash
bundle install
bundle exec jekyll serve
```

The site will be available at `http://localhost:4000`.

## Structure

| Path | Purpose |
|---|---|
| `_config.yml` | Site config (title, author, plugins) |
| `index.html` | Landing page with bio |
| `Gemfile` | Ruby / Jekyll dependencies |
| `_posts/` | Blog posts |
| `_pages/talks.md` | Talks & presentations |
| `assets/images/` | Static assets (headshot, etc.) |
